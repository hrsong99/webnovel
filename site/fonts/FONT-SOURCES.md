# Bundled font sources

Both families are distributed under the SIL Open Font License 1.1. The license text is stored in `OFL.txt`.

- **Maru Buri Regular / SemiBold** — https://github.com/fonts-archive/MaruBuri
- **Pretendard Variable** — https://github.com/orioncactus/pretendard

The font files are bundled so the reading experience does not depend on a third-party CDN at runtime.
